🔎 영상 발굴 설정

키는 이 브라우저의 로컬 저장소에만 보관되며 Google YouTube API 요청에만 사용됩니다.
검색은 국가별 YouTube 검색 결과를 조회수순으로 가져온 뒤 실제 통계를 확인해 기준 미달 영상을 제외합니다.

🔑 API 키 발급 방법

  1. Google Cloud Console 접속
  2. 프로젝트 생성 후 YouTube Data API v3 사용 설정
  3. 사용자 인증 정보에서 API 키 생성
  4. 키를 위 입력란에 붙여넣기
YouTube Data API는 기본 할당량이 있으며 검색 요청은 할당량을 사용합니다. API 키를 외부에 공유하지 마세요.
